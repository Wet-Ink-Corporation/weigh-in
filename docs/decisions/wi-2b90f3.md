# Should Weigh-In run reliance drills, occasionally marking a deliberately weaker option as recommended, to check that you still review?

## Context and problem statement

You expect to accept the recommendation most of the time. Pre-selected defaults are strong and disclosure does not weaken them, so an unmeasured rubber stamp is the main way this skill could make your decisions worse.

Door: two-way. Drills can be switched off at any sitting.

Timing: Decide now. Nothing will arrive to change this except your own override rate, which every option already measures.

Resolve by: before slice 2 metrics ship.

Evidence:

- [Jachimowicz 2019] Defaults shift choices with an overall effect of d = 0.68 across 58 studies; perceived endorsement is one of the moderators.
- [Bruns 2018] Disclosing a default does not weaken it.
- [Vaccaro 2024] Human–AI teams did worse than the better of the two on decision tasks (g = −0.23, 106 studies).
- [Ma 2025] Options-first deliberative display raised accuracy from 52.4% to 59.8% but median time per decision from 33 s to 236 s.

## Considered options

### A. Yes, two-way items only, 1 in 30 for 60 days (chosen)

A drill marks a weaker option as recommended on a two-way item and is disclosed before the sitting writes anything back.

- Holds if: one extra careful look per 30 items is worth a measured check on your review habit
- If wrong: mild annoyance; a missed drill is reverted before write-back, so nothing wrong is recorded

### B. No drills; watch override rate and time-to-decide

Trust the metrics every sitting already records.

- Holds if: override rate and time-to-decide are enough signal that you still review
- If wrong: a rubber-stamp habit goes unseen, because a low override rate looks the same as good recommendations

### C. Never pre-select; options first on every item

Show options and evidence before any recommendation, on every item.

- Holds if: you accept roughly seven times longer per decision
- If wrong: every sitting slows down, and the habit of running /weigh-in erodes

| Criterion | A | B | C |
|---|---|---|---|
| Detects rubber-stamping | Yes | No | Prevents it |
| Time per sitting | Same, plus rare drills | Same | About 7x |
| Risk to recorded decisions | None | None | None |

## Decision outcome

Chosen: **A. Yes, two-way items only, 1 in 30 for 60 days**, decided 2026-09-26T18:16:08Z.

The card's recommendation was A (recommended and pre-selected).
Trade-off: You are trading a rare moment of friction for evidence that your acceptances are real reviews.
What would flip it: Your override rate in the first 60 items is above about 15%. That already shows active review, so B.
Why it might be wrong: The evidence for drills is one study in a different setting. For a single expert reviewing his own architecture, a drill may feel like noise and cost more trust in the tool than it earns.
Stability: 4 of 4 (Opus pick plus 3 Sonnet samples, each with the option order permuted and the recommendation removed). All samples judged options written by the same author, so this checks order and framing bias, not authorship bias.
